# Changelog

## 1.1.0+26.3 – 2026-10-12

- Minecraft Java 26.3 mit Fabric und Java 25.
- Ingame-Soundboard mit acht Slots, WAV-/MP3-Import und lokaler bzw. Voice-Chat-Ausgabe.
- Echtzeit-Stimmeffekte: Tief, Hoch, Roboter, Funk, Echo und eigene Tonhöhe.
- Lautstärke, Effektanteil, Mikrofontest, Hotkeys und gespeicherte Einstellungen.
- Menüs und HUD nutzen die Minecraft-26.3-Schnittstellen; Tasteneingaben verwenden die neuen SDL-gestützten Minecraft-Keycodes.
- Geprüft mit Fabric Loader 0.19.5, Fabric API 0.162.0+26.3 und Simple Voice Chat 2.6.24+26.3.
- 27 Audiotests, Start mit/ohne Voice Chat und Menü-Screenshots im Minecraft-Client.

Ein Gespräch mit zwei Spielern auf einem echten Server wurde noch nicht getestet. Die 26.3-Ausgabe von Simple Voice Chat 2.6.24 ist als Beta veröffentlicht.
