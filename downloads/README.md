# Downloads für Minecraft Java 26.3

**[voicedeck-1.1.0+26.3.jar herunterladen](voicedeck-1.1.0%2B26.3.jar)**

[ZIP mit Mod, Anleitung und Screenshots](VoiceDeck-1.1.0-Fabric-26.3.zip) · [GitHub-Release](https://github.com/DunklerK3ks/VoiceDeck/releases/latest)

Die JAR gehört in den `mods`-Ordner eines Fabric-Profils für Minecraft Java 26.3. Eine ältere VoiceDeck-JAR vorher entfernen.

Zusätzlich werden [Fabric Loader ab 0.19.5](https://fabricmc.net/use/installer/) und [Fabric API für 26.3](https://modrinth.com/mod/fabric-api/versions?g=26.3) benötigt. Für Voice-Changer, Übertragung an andere Spieler und MP3-Import außerdem [Simple Voice Chat 2.6.24 für Fabric 26.3](https://modrinth.com/plugin/simple-voice-chat/version/OLnMVWXy) installieren. Diese Voice-Chat-Ausgabe ist als Beta veröffentlicht.

Java 25 wird benötigt. Mit **B** das Menü öffnen.

Die vollständige Anleitung steht in [README.md](../README.md). Die Prüfsummen der herunterladbaren Dateien stehen in [SHA256SUMS.txt](SHA256SUMS.txt).
